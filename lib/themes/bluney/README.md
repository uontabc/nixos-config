# Bluney theme sources

Vendored from <https://github.com/Mark44928/Bluney> at commit
`2d34b67aad362e02f7d1161b1550be2d6e9ef5b8` (MIT; see `LICENSE`).

Unmodified upstream files:

- `palette.json`
- `colors/bluney.vim`, `colors/bluney-light.vim`
- `bluney-light.theme` (upstream `btop/bluney-light.theme`)

`../../theme.nix` selects the light palette for shared application colors.
`noctalia.nix` maps the original dark/light palettes to Noctalia's version 2
palette format, preserving the upstream terminal colors. GTK 2 and Fcitx5
adapters are generated by their desktop modules; GTK 3/4, Qt, Niri, Kitty and
btop use Noctalia's existing template integration.

Noctalia's GUI overrides in `~/.local/state/noctalia/settings.toml` take
precedence over Nix defaults. To select this palette in an existing session:

```sh
noctalia msg color-scheme-set custom Bluney
noctalia msg theme-mode-set light
noctalia msg config-set theme.shell_mode '"follow"'
noctalia msg config-set theme.terminal_colors '"palette"'
noctalia msg templates-apply
```

The canonical colors are in `palette.json`; the upstream README's tables may
still show an older green palette.
